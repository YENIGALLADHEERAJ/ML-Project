02 / Existing work → our contribution

Built on research.
Made inspectable.

The contribution is a source-controlled evaluation and a working comparison tool—not a new implant-identification algorithm.

DimensionWhat already existsWhat this project adds
ModelsRandom forests, EfficientNet-B3, Swin-T and ConvNeXt-T are established methods.Controlled comparisons of these methods on one source-aware joint-recognition benchmark.
ApplicationPublished systems investigate anatomy recognition and orthopaedic implant identification.A narrower reliability question: how much does pooled evaluation overstate transfer to an unfamiliar source?
EvaluationShortcut learning and external validation are established research topics.Six public sources, a multi-joint decoupled source, anatomy-free controls and paired saved predictions.
DemonstrationSingle-model label/confidence displays are common interfaces.Four actual checkpoints on the same input, source-held-out comparison, Grad-CAM and linked benchmark evidence.
EvidenceDataset and architecture papers supply inputs and precedents.Frozen analysis plan, grouped splits, checkpoint hashes, recorded deviations and independently checked saved metrics.
The project evolved when the evidence changed

From a high score
to a better question.

  1. 01

    Initial prototype

    Hip/Knee/Shoulder classification produced very high pooled scores. An audit showed labels were strongly tied to dataset source, so those scores could not establish anatomical generalization.

  2. 02

    Source-controlled study

    The project expanded to six sources and tested pooled, source-balanced, source-decoupled and held-out-source protocols, with simple non-anatomical controls.

  3. 03

    Integrated workbench

    The same study checkpoints now run on an uploaded image or held-out specimen. Predictions link to source sensitivity, uncertainty and the underlying evidence.

  4. 04

    Evaluation-ready evidence

    Automated checks, literature comparisons, a demo sequence and viva preparation make the system explainable and reviewable. Human validation and contribution evidence remain explicit gaps.

Why it is useful

A tool for asking
better evaluation questions.

Students can explain an end-to-end ML system. Researchers can inspect how training-source changes affect the same image. Evaluators can follow a result back to a baseline and saved artifact.

The measured contribution is evidence of source sensitivity in this benchmark. We have not demonstrated clinical benefit, deployment at hospitals, cost savings or superiority to commercial implant systems.

What would strengthen it next?

  • Clinician verification of provisional knee labels.
  • Replication on another genuinely independent multi-joint source.
  • Broader training and domain-generalization comparisons.
  • Real user feedback, load tests and deployment validation.
