Scientific evidence

Results are reproducible.
Limits stay visible.

Saved predictions independently reproduce 438 balanced-accuracy summary cells. All 29 study checkpoint hashes match the supplied registry. The live API reproduces the nine shipped sample outputs.

These checks support implementation integrity. They do not validate provisional knee labels, establish clinical performance or prove causal implant effects.

Independent dataset check

We froze the expanded model and its cutoffs before scoring 54 BTXRD radiographs from the public mirror. Each image had exactly one of the three target joint tags.

The Elbow output frequently appeared on images tagged Knee or Shoulder. The cohort contains only five elbow-tagged images. We used the published dataset tags and did not obtain a separate clinician review.
