Understand this website
in two minutes.

OrthoTrace asks one question: when an AI names the joint in an X-ray, is it looking at the bone, or just at the dataset the picture came from? This page explains what you will see and how to read it.

A high score is not proof of understanding.

Public X-ray collections mostly hold one joint each. A model can learn "this size of picture means hip" and score almost perfectly, then fail on pictures from somewhere new. We measured how often that happens and built a tool that lets you see it on any X-ray.

The short version: on familiar pictures our five main models score 0.99 to 1.00. On a dataset they never saw, they score 0.50 to 0.69. Random guessing scores 0.33.

PLAIN-WORDS GLOSSARY

Words you will meet

On every page, dotted words show their meaning when you hover over them or tap them.

Balanced accuracy
A fair score from 0 to 1: the average, over Hip, Knee and Shoulder, of how many images were named correctly. Random guessing scores about 0.33.
Recall
Of all the real hips, the share the model correctly called hip. Done per joint, then averaged.
Pooled test
All datasets are mixed and split at random, so test pictures look like the training pictures. An easy test.
Source-decoupled test
A test on a dataset the model never saw during training. A hard and fair test of 'will it work somewhere new?'.
Generalization gap
The pooled score minus the new-dataset score. A big gap means the easy test was flattering the model.
Dataset source
The collection a picture came from, such as a hospital, a website or a research group.
Checkpoint
A saved, trained model file. Our four checkpoints use the same network and differ only in the data they were trained on.
EfficientNet-B3
A well-known image-recognition neural network. All four checkpoints in the demo use it.
Fine-tuning
Taking a network that already learned from millions of everyday photos and training it a little more on X-rays.
Grad-CAM
A heat map showing which parts of the image pushed the model towards its answer. It shows sensitivity, not proof the model understands anatomy.
Softmax confidence
How the model splits 100% between its possible answers. It is not the chance of being right.
Shortcut probe
A small model that sees only file properties (size, shape, format, file size), never the picture. If it gives the same answer, the answer could be a shortcut.
Shortcut
A clue that predicts the answer but has nothing to do with the real subject, like image size or file type.
Random forest
Many small decision trees that vote. Here it is given only image size and file properties, never the bones.
FracAtlas
A public X-ray collection that contains all three joints. We use it as the 'new dataset' test.
Provisional label
A label from our team's visual check that a clinician has not yet reviewed.
Calibration
Whether '90% sure' really means right 90 times out of 100.
ECE
Expected calibration error: how far the model's stated confidence is from how often it is actually right.
Out-of-distribution (OOD)
An input unlike the training data, such as a hand X-ray shown to a hip, knee and shoulder model.
Confidence interval
A range showing how much a score could wobble because the test set is finite. It is not a promise about future hospitals.
Data leakage
When test pictures secretly resemble training pictures, making scores look better than they are.
Seed
A number that fixes a run's randomness. Repeating with several seeds shows how stable a result is.
QUESTIONS PEOPLE ASK

Short answers

Is this a medical tool?

No. It is an academic research project. It does not diagnose anything, has not been tested in hospitals and must not be used for patient care.

What does the AI actually predict?

Whether an X-ray shows a hip, a knee or a shoulder. A second model also flags hand, leg and elbow. It does not detect fractures, diseases or implant brands.

Why are there four models for one image?

They are the same type of network, trained on different data. One saw everything. The others each missed one dataset. If they disagree on an image, the training data is changing the answer.

What is the shortcut probe?

A small model that sees only file properties: width, height, shape, format and file size. It never sees the picture. If it names the same joint as the main model, that answer could come from a shortcut instead of anatomy.

Does a matching probe prove the model cheated?

No. It only shows the answer could be produced without looking at bones. A disagreement does not prove the model understands anatomy either.

Why do scores fall on a new dataset?

Because each dataset has its own habits: picture size, borders, file type. A model can learn those habits instead of the anatomy. On a new dataset the habits change and the score collapses.

Can I trust a high score on a public dataset?

Only if the model was also tested on a dataset it never saw. That is the main lesson of this project.

Why does the online demo not run live?

The public site is static hosting, so it can only show saved samples. Live upload, the heat map and the shortcut probe need the Python server, which you can start on your own computer with start.ps1.

Is my image stored?

No. On the live server an uploaded image is processed in memory and discarded. Do not upload images that could identify a patient.

What is still unproven?

Clinical use, the cause of the failures (implants are a suspect, not proven), and performance at a new hospital. The limitations page lists everything.

Project scopeThe models classify Hip, Knee or Shoulder. This project evaluates how joint-recognition models are tested. It is an academic project, not a medical device, and it does not diagnose disease or identify implant brands.
