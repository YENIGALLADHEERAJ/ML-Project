Reproducibility

Check it yourself

Everything needed to re-derive the reported numbers from the frozen artifacts, apart from the third-party image data, which must be downloaded from the original hosts.

What is included

  • Pipeline scripts and the step-by-step guide (REPRODUCIBILITY.md)
  • Frozen analysis plan with SHA-256 hashes (plan)
  • Independent audit script with 13 checks (audit_results.py)
  • Pinned environment (requirements.txt: Python 3.11, torch 2.4.1, scikit-learn 1.9.0)
  • Per-checkpoint hashes; this site's API reports the SHA-256 prefix of the four demo checkpoints at /api/health
Not includedSource images (licences differ; download from the original hosts) and the full set of 29 checkpoints. Fine-tuning is not bit-reproducible on GPU; third decimals may vary.

Expected key outputs

Pooled BA, 5 primary models0.993–1.000
Decoupled BA0.498–0.686
H1 supported5 / 5 (Holm p = 0.0025)
RF on metadata / dimensions, pooled → decoupled0.960 / 0.971 → 0.333
Audit checks13 / 13 pass

Run this site

pip install -r site/api/requirements.txt
cd site/api && uvicorn app:app --port 8000
# open http://localhost:8000

Without the API, the demo falls back to precomputed sample outputs and labels itself accordingly.

Project scopeThe models classify Hip, Knee or Shoulder. This project evaluates how joint-recognition models are tested; disease prediction and implant-brand identification are outside the implemented task.

OrthoTrace

A model evaluation workbench for hip, knee and shoulder radiographs. Compare checkpoints and investigate source sensitivity. Built as an academic project in source-aware orthopaedic AI.
