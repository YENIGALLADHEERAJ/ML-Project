Interpretation limitImplant presence is perfectly aligned with source here (hip and shoulder sources are implant images; no knee source is). It is a plausible confound, not a demonstrated cause.

Shortcut controls and image-feature baselines

Random forests use the listed features (pooled 0.88–0.97; decoupled 0.33–0.61). Dimensions and metadata contain no anatomy; image-derived features such as HOG can contain anatomical information. Frozen probes with image content: pooled ≈0.99, decoupled 0.50–0.66.

Is the source still decodable after pre-processing?

Within each joint, can a linear classifier on frozen embeddings tell which source an image came from? Mean balanced accuracy over hip, knee and shoulder (chance 0.33–0.50), development data, 5-fold group CV.

Does removing cues rescue the decoupled score?

No variant restores strong transfer; border removal and implant-blob inpainting are only partial controls.

Selective prediction

Keeping only the most-confident predictions helps on pooled data; under source shift the confident half stays wrong (accuracy ≤ 0.10 in the implant holdouts).

Project scopeThe models classify Hip, Knee or Shoulder. This project evaluates how joint-recognition models are tested; disease prediction and implant-brand identification are outside the implemented task.
