How to read the report.

Choose a sample or drop an X-ray on the left. This is what the report will show.

  1. Main answer The joint our main model thinks it sees, with a score. The score is how the model splits 100% between Hip, Knee and Shoulder, not the chance of being right.
  2. Four models The same type of network trained on different data: one saw everything, the others each missed one dataset. If they disagree, the training data is changing the answer.
  3. Six-region flags A second model that flags Hip, Knee, Shoulder, Hand, Leg and Elbow independently, each with its own cutoff.
  4. Heat map Drag the slider. Bright areas pushed the model towards its answer. It shows sensitivity, not proof the model understands anatomy.
  5. Image properties Size, shape, format and file size. These are the clues a shortcut could use.
  6. Shortcut probe A blind model that sees only those properties also guesses. If it agrees with the main answer, the answer could be a shortcut.
Project scopeThe models classify Hip, Knee or Shoulder. This project evaluates how joint-recognition models are tested; disease prediction and implant-brand identification are outside the implemented task.
